# ADR-001：W1 范围与查询边界

状态：用户交接已批准；实现证据另存，本文不是验收结论。

批准依据原文：“确认 W1-A 范围、契约和验收草案，批准 low 按 P1–P3 执行。”
确认时间：未提供。此批准不替代执行会话操作门。

W1-A 仅实现精确单文件路径校验、文件元数据、只读访问检查、分块 SHA-256 和本地 S0 JSON；不解析记录、不统计行数、不画像、不执行 SQL、无产品模型调用。

W1-B 才验证读取契约与画像。后续 W1 只接受宿主构造的参数化画像查询与预定义模板，SQL 仅 SELECT/WITH；必须验证模板来源、参数、路径及结果边界并做反向测试。自由 SQL、AST、通用隔离与资源限制框架不在 W1 范围。准备稿中更宽的通用查询设计不是本轮实施要求，也不代表这些控制已实现。

路径策略：精确生产文件允许列表、tests/fixtures 非递归目录、outputs/W1-A 输出边界；CLI 与配置不能增加权限。保守拒绝任意符号链接/Windows 重解析组件、UNC、设备路径、URI、通配符、上级路径片段和非规范目标。该选择缩小支持形式，不放宽授权。路径检查不宣称抵御具有同机并发写入权限的攻击者在检查后替换路径；运行期间要求授权目录不被并发修改。

环境：已有 Python 创建独立 .venv，--without-pip；仅标准库。当前进程可控缓存/临时目录在项目 .cache 下，禁用字节码写入；不迁移或删除系统缓存。

现有目录变更：P1 实测项目已存在；用户批准进一步检查，工具实测顶层为空且项目祖先无链接/重解析点，随后用户确认 P2 使用现有空目录。不覆盖旧文件、不初始化 Git。

网络观察边界：测试/CLI 的 Python 审计钩子拒绝 socket 事件及启动子进程；这是本进程观察，不是全系统网络隔离。无 provider 或模型调用入口。
