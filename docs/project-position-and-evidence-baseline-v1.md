## 1. 项目定位

**面向封闭分析意图、提供可复核结论与证据的受控分析系统。**

需求诊断与研究方案是系统的前置能力；不再使用无条件的“能证明结论可信”。系统支持在已确认的数据版本、方法前提和指标口径下复核结论，不认证源数据真实、业务语义天然正确、总体代表性或因果效果。

执行时的四项固定原则：

1. 业务数值全部由确定性工具／流程产生；模型不计算、不生成数值、不替工具舍入。
2. 执行方法库固定且封闭，只用已审查、测试、批准发布的方法版本。方法审查是必要来源之一，不是可信的充分条件。
3. 执行入口为封闭intent；未知或前提不满足的意图不获得执行资格，不因人批准或模型推荐扩大方法范围。
4. 模型方法参与仅在方法入库前的候选通道。未来入口翻译层若使用模型，是明确的“执行前意图草稿”例外；两条通道均不能直接执行、修改已批口径或代表人工决定。

W2-B2真实方案解释接入停止续作。W3计算、校验与本地报告草稿均不调用模型，包括本地模型；产品DeepSeek选择保留为未来获批模型部件的选择，不借此默默换provider或推定调用许可。

## 2. 必要证据筛选基线

判据：**缺少它会导致错误结论、越权／泄露、不可逆损坏或未授权费用→必要；只改善审计便利→不要求。**

适用于W3及后续新标准；不追改W1／W2冻结标准、已有测试、实现检查或验收结果。引用既有核验函数时仍满足其原接口，不能借“精简”跳过现有输入验证或清理旧证据。

| 项目 | 后续要求 | 防止的错误／损失 |
|---|---|---|
| 字节级哈希绑定 | 保留实际被消费的必要输入、口径、模板／源码及结果身份；引用必须解析到相符字节 | 用错数据、旧批准或错误结果 |
| 版本绑定 | 数据／问题／规则／方法／口径／策略及批准绑定；变化停止 | 方法适用错误、口径错配 |
| 唯一终态与原子发布 | 保留；必需结果完成后发布，pending与tmp不视为success | 将部分计算／收尾失败当成功 |
| 路径边界与禁止覆盖 | 保留；批准来源、受控参数、新run、已有目标拒绝 | 越权读取、证据损坏 |
| 四道人工门 | S2受理、S3路径／口径、S3.5策略、S6业务解释；外发另有动作授权 | 技术结果冒充业务决定 |
| ADR-005责任与时间 | 保留；confirmed_at与recorded_at分开，旧receipt时间语义原样引用 | 伪确认、责任转移 |
| 数值与声明核验 | 工具证据、独立合成参考、执行／口径／边界校验及主要反向 | 算错、报告值错、越界解释 |
| 敏感内容与错误处理 | 保留不回显／落盘原始行、标识值、密钥的控制与关键拒绝测试 | 泄露或把输入当指令 |
| 资源与失败控制 | 保留本轮受信查询所需限额、超时／受控失败与非零退出 | 无界计算、失败冒充成功 |
| 精确token上界、tokenizer计数、chat_template解析 | 不作为W3要求；W3零模型调用，token／usage／费用not_applicable | 不借不适用事项阻塞业务计算 |
| 跨run完整逐文件产物清单 | 不要求；保留本次结论必需的引用／哈希，不扫全历史run | 不建立仅为审计便利的全量索引 |
| 输出／错误／trace哨兵扫描范围报告 | 不要求；不取消敏感内容控制与直接测试断言 | 精简报告，不精简防泄露 |
| 同一结论多次独立恢复核验 | 不要求重复进程／恢复证明；保留消费入口核验和主要版本变化反向 | 不以原子发布替代输入有效性 |

哈希证明字节身份，不是业务正确性或抵御协同篡改的认证。测试通过只支持对应契约和场景，不宣传总体准确率。

## 3. 预算保护的准确表述

未来预算门可合并请求次数、最大尝试次数、已知单次／累计消费判断及发送资格，复用现有累计账本设计；不宣称本地门能约束在途单次实际费用。

- 已知消费超批准阈值或次数耗尽：拒绝后续发送；发送前持久记录尝试，默认无自动重试。
- 单次已知费用事后超阈值：保留消费并暂停；不称该请求曾被发送前费用硬上限约束。
- 计费／usage未知：显示“已知累计＋未结算风险”，保留风险记录并暂停，不能显示为零或已核实全部扣款。
- 最坏风险可能涉及账户可用余额；若有授信／自动补款，风险还可能扩大。账本显示、输出上限或本地超时不证明风险封顶。
- 真实usage／结算与provider硬限额未验收。未来付费风险必须另版／ADR、准确风险授权与接口测试；本文件不批准金额、不计算费用、不放行旧C205。

## 4. W3证明场与S6边界

已有部分使用阶段证据：历史生产画像及模板重跑、源前后身份一致、真实S2 accept及S3方案／口径approve。**尚无完整S4→S5→S6真实业务结论闭环。**

W3只使用唯一方法`M-BEHAVIOUR-RECORDS`，新增一次获批真实数据计算，完成S5执行／口径／边界三层校验并产出本地报告草稿。这是W3必需项，不是加分项。

允许结论仅为绑定真实数据版本的行为代码原始记录计数及限定描述。不称订单、支付、严格转化、日期覆盖、总体或业务效果。缺证据时拒绝成功报告，不让模型补齐。

报告草稿生成从原W4-A方向提前纳入W3／E3；W3仍结束于S5，human_review_state=pending。完整闭环还须随后独立S6人工业务解释确认，外发另获许可。W3通过不能自称S6完成；详见[W3方案](W3-plan-v1.md)。
